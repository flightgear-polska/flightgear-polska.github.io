Jeśli planujesz loty liniowcami z naszego [katalogu samolotów](/samoloty/) tak jak prawdziwy dyspozytor, SimBrief Import eliminuje najbardziej nudną część przygotowań – ręczne przepisywanie danych z planu lotu do FMC.

## Co dostajesz

- Import trasy, paliwa, masy i wiatrów na wysokości prosto z konta SimBrief
- Mniej miejsca na błędy przy długich trasach z wieloma waypointami
- Spójność danych między dispatchem a tym, co faktycznie wgrywasz do komputera pokładowego

## Dla kogo

Dla pilotów liniowych, którzy chcą latać zgodnie z procedurami – np. na Airbusie A320 albo Boeingu 737-800 z naszego katalogu. Mniej przydatny przy prostych lotach VFR Cessną, gdzie planowanie trasy i tak robi się intuicyjnie.

## Instalacja

1. Załóż darmowe konto na SimBrief i wygeneruj plan lotu.
2. Pobierz addon z repozytorium GitHub powyżej.
3. Dodaj folder addonu w launcherze (zakładka **Add-ons**).
4. Skonfiguruj swój identyfikator SimBrief według instrukcji w pliku README repozytorium – każdy samolot z FMC może mieć inny sposób wczytania danych.
